# Результаты замера Debug vs Release
| режим | Запуск 1 | Запуск 2 | Запуск 3 | Запуск 4 | Запуск 5 | Минимум |
| Debug |  360мс   |  395мс   |  366мс   |  750мс   |  370мс   |  360мс  |
|Release|  354мс   |  116мс   |  117мс   |  122мс   |  112мс   |  112мс  |
В моём эксперементе Release оказался быстрее Debug примерно в 3.2 раза.
Что я обнаружила при сравнении IL:
1. в Debug присутствует инструкцуия nop, которых нет в Release;
2. в Release уменьшилось количество промежуточных операций с локальными переменными;
3. Количество IL-инструкций в методе Add() изменилось с 11 до 4
